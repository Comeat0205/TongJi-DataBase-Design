# 文件命名规范

全组新增代码统一遵循本规范。新建业务文件时**对照会员模块（B 维护的样板）**，把 `Member` / `Members` 换成自己模块的实体名即可。

---

## 1. 命名总原则

| 原则 | 说明 | 示例 |
| --- | --- | --- |
| 业务名用英文 PascalCase | 类名、文件名首字母大写 | `Coach`、`GroupCourse` |
| 接口以 `I` 开头 | C# 接口惯例 | `ICoachRepository` |
| 后端文件名 = 类名 | 一个文件一个主类 | `CoachDto.cs` → `class CoachDto` |
| 前端 API 文件用小写复数 | 与 REST 资源名一致 | `coaches.ts`、`members.ts` |
| 前端页面以 `View` 结尾 | Vue 页面组件 | `CoachListView.vue` |
| 不改已有 Entity 文件名 | 实体由数据库反向生成 | 保留 `Groupcourse.cs`，不要强行改名 |
| Git 分支全小写 + 连字符 | 与模块 feature 名一致 | `feature/group-course` |
| 不修改他人模块文件 | 只在自己负责的目录/文件范围内新增 | — |

## 2. 后端命名（以 Member 为模板）

新增模块通常 **6 类新建文件 + 2 处 DI 追加一行**。

### 2.1 分层对照

| 层级 | 目录 | 已有模板 | 新建规则 | 示例（教练） |
| --- | --- | --- | --- | --- |
| 实体 | `Domain/Entities/` | `Member.cs` | `{Entity}.cs`（通常已有） | `Coach.cs` |
| 仓储接口 | `Domain/Interfaces/` | `IMemberRepository.cs` | `I{Entity}Repository.cs` | `ICoachRepository.cs` |
| 仓储实现 | `Infrastructure/Repositories/` | `MemberRepository.cs` | `{Entity}Repository.cs` | `CoachRepository.cs` |
| 返回 DTO | `Application/DTOs/` | `MemberDto.cs` | `{Entity}Dto.cs` | `CoachDto.cs` |
| 请求 DTO | `Application/DTOs/` | `LoginRequestDto.cs` | `Create{Entity}RequestDto.cs` 等 | `CreateCoachRequestDto.cs` |
| 应用服务接口 | `Application/Interfaces/` | `IMemberAppService.cs` | `I{Entity}AppService.cs` | `ICoachAppService.cs` |
| 应用服务实现 | `Application/Services/` | `MemberAppService.cs` | `{Entity}AppService.cs` | `CoachAppService.cs` |
| HTTP 控制器 | `Api/Controllers/` | `MembersController.cs` | `{Entities}Controller.cs`（复数） | `CoachesController.cs` |
| DI（追加） | `Application/Extensions/DependencyInjection.cs` | — | 加一行注册 | 或由 A 合并 PR 时加 |
| DI（追加） | `Infrastructure/Extensions/DependencyInjection.cs` | — | 加一行注册 | 同上 |

### 2.2 类名与文件名一致

```text
CoachDto.cs          →  CoachDto
ICoachAppService.cs  →  ICoachAppService
CoachesController.cs →  CoachesController
```

### 2.3 Controller 与 API 路径

Controller 用**复数**，`[Route("api/[controller]")]` 自动生成前缀：

| 文件 | API 前缀 |
| --- | --- |
| `MembersController.cs` | `/api/members` |
| `CoachesController.cs` | `/api/coaches` |
| `GroupCoursesController.cs` | `/api/groupcourses` |
| `EquipmentController.cs` | `/api/equipment`（器材不可数，不加 s） |

### 2.4 DTO 命名

| 用途 | 格式 | 示例 |
| --- | --- | --- |
| 查询返回 | `{Entity}Dto` | `CoachDto` |
| 创建请求 | `Create{Entity}RequestDto` | `CreateCoachRequestDto` |
| 更新请求 | `Update{Entity}RequestDto` | `UpdateMemberRequestDto` |
| 统一响应 | `ApiResponse<T>` | 共用，不新建 |

### 2.5 Entity 文件名（已有，禁止重命名）

| 文件名 | Oracle 表 | 类名 |
| --- | --- | --- |
| `Member.cs` | `MEMBER` | `Member` |
| `Coach.cs` | `COACH` | `Coach` |
| `Groupcourse.cs` | `GROUPCOURSE` | `Groupcourse` |
| `GroupCourseBooking.cs` | `GROUP_COURSE_BOOKING` | `GroupCourseBooking` |
| `MemberBenefitCard.cs` | `MEMBER_BENEFIT_CARD` | `MemberBenefitCard` |
| `Cardproduct.cs` | `CARDPRODUCT` | `Cardproduct` |
| `Checkinout.cs` | `CHECKINOUT` | `Checkinout` |
| `Capacitylog.cs` | `CAPACITYLOG` | `Capacitylog` |
| `Personalpackage.cs` | `PERSONALPACKAGE` | `Personalpackage` |
| `Ptbooking.cs` | `PTBOOKING` | `Ptbooking` |
| `Repairrecord.cs` | `REPAIRRECORD` | `Repairrecord` |
| `Inspectiontask.cs` | `INSPECTIONTASK` | `Inspectiontask` |

Repository / DTO / Controller 用规范英文；引用 Entity 时**按上表已有类名**（如 `Groupcourse`，不是 `GroupCourse`）。

## 3. 前端命名（以 Member 为模板）

| 类型 | 目录 | 已有模板 | 新建规则 | 示例 |
| --- | --- | --- | --- | --- |
| API | `src/api/` | `members.ts` | `{resources}.ts` 小写复数 | `coaches.ts` |
| 页面 | `src/views/` | `MemberProfileView.vue` | `{Feature}View.vue` | `CoachListView.vue` |
| 路由 | `src/router/index.ts` | — | path 小写连字符；name 小驼峰 | `/coaches`，`coach-list` |
| 状态 | `src/stores/` | `auth.ts` | `{domain}.ts` 小写 | 按需 |

**TypeScript 接口**字段用小驼峰：

```typescript
export interface Coach {
  coachId: number
  coachName: string
}
```

**页面命名建议：**

| 功能 | 格式 | 示例 |
| --- | --- | --- |
| 列表 | `{Entity}ListView.vue` | `CoachListView.vue` |
| 详情 | `{Entity}ProfileView.vue` | `MemberProfileView.vue` |
| 编辑 | `{Entity}EditView.vue` | `MemberEditView.vue` |
| 预约 | `{Entity}BookingView.vue` | `GroupCourseBookingView.vue` |
| 员工端列表 | `Admin{Entity}ListView.vue` | `AdminEmployeeListView.vue` |

## 4. Oracle 脚本命名

脚本目录：`database/oracle/`

| 类型 | 子目录 | 文件名 | 对象名（Oracle 内） |
| --- | --- | --- | --- |
| 视图 | `views/` | `v_{描述}.sql` | `V_MEMBER_BOOKING_SUMMARY` |
| 存储过程 | `procedures/` | `sp_{描述}.sql` | `SP_BOOK_GROUP_COURSE` |
| 函数 | `functions/` | `fn_{描述}.sql` | `FN_IS_CARD_VALID` |
| 触发器 | `triggers/` | `trg_{描述}.sql` | `TRG_CHECKIN_UPDATE_VENUE` |

规则：文件名全小写 + 下划线；只**新增**自己的 `.sql`，不覆盖他人脚本。

## 6. Git 分支与提交

### 分支名（代号 → 分支）

| 代号 | 分支 |
| --- | --- |
| A | `main`（仅合并，不直接开发业务） |
| B | `feature/member-template` |
| C | `feature/basic-info` |
| D | `feature/membership-card` |
| E | `feature/venue-checkin` |
| F | `feature/group-course` |
| G | `feature/personal-training` |
| H | `feature/payment-marketing` |
| I | `feature/maintenance` |
| J | `feature/schedule` |

格式：`feature/{module}`，全小写，连字符分隔，不用中文、不用姓名。

修复可用：`fix/{description}`，例如 `fix/login-error-message`。

### Commit 信息

| 类型 | 格式 | 示例 |
| --- | --- | --- |
| 新功能 | `feat(模块): 描述` | `feat(coach): 教练列表查询` |
| 修复 | `fix(模块): 描述` | `fix(auth): 修复登录提示` |
| Oracle | `feat(oracle): 描述` | `feat(oracle): 添加入场触发器` |

## 7. 常见错误

| ❌ 错误 | ✅ 正确 | 原因 |
| --- | --- | --- |
| `member_controller.cs` | `MembersController.cs` | C# 用 PascalCase |
| `MemberController.cs` | `MembersController.cs` | 资源用复数 |
| `CoachService.cs` | `CoachAppService.cs` | 与 `MemberAppService` 一致 |
| `CoachRepo.cs` | `CoachRepository.cs` | 写全称 |
| `CoachList.vue` | `CoachListView.vue` | 页面加 View |
| `Coach.ts` | `coaches.ts` | 前端 api 小写复数 |
| 重命名 `Groupcourse.cs` | 保持不动 | 实体勿改 |
| `feature/张三` | `feature/basic-info` | 分支不用姓名 |
| 覆盖他人 `.sql` | 只新增自己的脚本 | `database/oracle/` 各管各的 |
